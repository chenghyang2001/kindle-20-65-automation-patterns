# 程式碼審查

從以下角度審查程式碼。

## 安全性


- 認證與授權是否妥善
- SQL injection 與 XSS 風險
- 硬編碼的機密或憑證


## 品質

- 函式與變數命名是否清晰
- 重複的程式碼
- 錯誤處理是否充分


## 效能

- 不必要的迴圈或 N+1 查詢
- 可加快取的機會

每個問題依嚴重程度分類回報（Critical / Warning / Suggestion）。
