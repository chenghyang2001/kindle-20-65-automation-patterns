# MCP 轉 Skill 遷移範例

本目錄示範如何用 Claude Code Skill 取代一個簡單的 MCP server。

## 問題

一個只負責抓取文件或執行單一 CLI 工具的 MCP server，會帶來
基礎設施負擔（server 程序、設定、維護），但價值卻很有限。

## 解法

改用一個 Skill 檔（`SKILL.md`），搭配 `Bash(curl *)` 等內建工具即可。

## 取捨

| 面向 | MCP Server | Skill |
|--------|-----------|-------|
| 建置 | 需要 server 程序 | 只要一個 `.md` 檔 |
| 維護 | 需要持續更新 | 自給自足 |
| 能力 | 任意程式碼 | 受限於允許的工具 |
| 適合場景 | 複雜的有狀態操作 | 簡單、聚焦的任務 |

## 什麼時候該保留 MCP

- 工具需要在呼叫之間維持狀態
- 工具需要 OAuth 或複雜的認證
- 工具需要串流大量資料
- 多個專案共用同一個 server

## 什麼時候該改用 Skill

- 工具只執行單一 CLI 指令
- 工具只抓取公開文件
- 工具只做簡單的文字處理
- 架一個 server 的負擔不划算
