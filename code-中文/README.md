# Claude Code in Production — 範例程式碼

本倉庫為 Yosuke Morikawa 所著 **Claude Code in Production: 65 Automation Patterns for Hooks, Sub-Agents & CI/CD** 一書的官方範例程式碼倉庫。

## 關於本倉庫

本倉庫收錄書中講解的全部 65 個 pattern 的設定檔、腳本與 agent 定義。請依 part 編號瀏覽，找到各 pattern 對應的範例程式碼。

## 倉庫結構

| 目錄 | Patterns | 主題 |
|-----------|----------|--------|
| [part1-design/](./part1-design/) | P01–P10 | CLAUDE.md、Rules、Skills |
| [part2-hooks/](./part2-hooks/) | P11–P22 | Hooks — 完整 17 種事件目錄 |
| [part3-agents/](./part3-agents/) | P23–P31 | Sub-agent 設計與實作 |
| [part4-cicd/](./part4-cicd/) | P32–P39 | CI/CD 流水線自動化 |
| [part5-security/](./part5-security/) | P40–P47 | 權限與組織安全 |
| [part6-cost/](./part6-cost/) | P48–P56 | Token 成本最佳化 |
| [part7-workflows/](./part7-workflows/) | P57–P65 | 生產環境工作流 pattern |

## 使用方式

每個目錄都包含可直接使用的設定檔與腳本。
請將需要的檔案複製到你的專案中，並依你的環境調整。

大多數腳本與設定都可直接套用。
請查看每個檔案開頭的註解以取得 pattern 對照（例如 `# P14: ...`）。
