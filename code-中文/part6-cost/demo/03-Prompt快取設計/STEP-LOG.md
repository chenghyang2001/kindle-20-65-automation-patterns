## Step 2：理解「Exact Prefix Matching」的致命性

### 概念說明

快取的比對方式是**完全前綴匹配**——從第一個字元開始對比，
只要某一個位置不同，從那個位置之後的所有內容都必須重新計算。

### 情境練習

假設你的 CLAUDE.md 頂部是：

```markdown

## 技術堆疊
- Python 3.11
- FastAPI
```

## 本課重點

```
快取命中的唯一條件：
  本次送出的 Prefix == 上次送出的 Prefix（完全一樣，一個字元都不能差）

CLAUDE.md 分層策略：
  ✅ 頂部：技術堆疊、架構說明、命名規範（從不變）
  ⚠️ 中間：依賴套件版本、團隊規範（偶爾更新）
  ❌ 底部：今日 TODO、最新錯誤訊息、時間戳（每次都變）

最常見的快取殺手：
  - CLAUDE.md 頂部放時間戳
  - session 每次 import 不同的動態狀態
  - 系統提示包含環境變數（如當前時間）
```
