Deny > Ask > Allow 優先順序
三層按優先順序套用，Deny 永遠比 Ask 和 Allow 先生效。
🚫 Deny

永遠封鎖（最高優先）

無論使用者怎麼要求，這些操作絕對不執行。
常用規則：Bash(rm -rf*)、Bash(git push --force*)、Bash(DROP TABLE*)、mcp__playwright__*

❓ Ask

需要確認

每次執行前都必須讓使用者明確同意。
常用規則：WebFetch(*)（所有外部請求）、Bash(curl*)、特定的 MCP 工具。

✓ Allow

自動放行

在已知安全範圍內自動執行。
常用規則：Read(*)、Write(code/*)、Bash(python -m pytest*)
