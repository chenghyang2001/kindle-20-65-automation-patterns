Token 帳單四欄位
--output-format json 的回傳中有四個關鍵欄位，對應不同計費項目。
📥
input_tokens
你傳給 Claude 的 tokens（含 context）
$3/M（Sonnet）
📤
output_tokens
Claude 產出的回應 tokens
$15/M（Sonnet）
💾
cache_read_tokens
從快取讀取的 tokens（便宜 10×）
$0.3/M（折扣）
✏️
cache_write_tokens
寫入快取的 tokens（略貴）
$3.75/M（1.25×）
# 用 jq 提取帳單資訊 RESULT=$(claude -p "..." --output-format json) echo $RESULT | jq '{cost: .cost_usd, input: .input_tokens, output: .output_tokens}'

Prompt 快取三層設計
把最穩定的 Context 放在最前面，讓快取命中率最大化。
1

系統層（永遠需要）

CLAUDE.md 的全域規則、語言鐵律、禁止硬編碼路徑。這層幾乎不變，快取命中率接近 100%。

2

專案層（條件需要）

專案 CLAUDE.md、技術堆疊說明、資料庫連線規則。每個專案一份，跨 session 複用。

3

任務層（隨需呼叫）

當前任務的 context：開啟的檔案、搜尋結果、Git diff。每次任務不同，不依賴快取。

Sub-agent 套利
用 Haiku 做偵察，只回傳路徑；讓 Sonnet 只讀必要檔案。節省大量 output tokens。
❌ 傳統做法
Sonnet 直接搜尋所有檔案
讀取：100 個檔案 × 平均 200 行
= 20,000 行 → ~40,000 tokens
費用：$0.60
→
✅ Sub-agent 套利
Haiku 偵察：只回傳 3 個相關路徑
Sonnet 精讀：3 個檔案 × 200 行
= 600 行 → ~1,200 tokens
費用：$0.002
節省 299× output tokens
