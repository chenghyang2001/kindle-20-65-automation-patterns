PreToolUse：在 Claude 執行任何工具之前觸發。可用於
  • 🚫 阻擋危險操作（exit 1 → Claude 收到 Error，停止執行）
  • 📝 記錄操作意圖（exit 0 → 放行，但先寫日誌）
  • 🔍 參數驗證（檢查路徑、命令格式是否符合規範）
# settings.json { "hooks": { "PreToolUse": [{ "matcher": "Bash", "hooks": [{ "type": "command", "command": "bash ~/.claude/hooks/check-cmd.sh" }] }] } }
PostToolUse：工具執行完成後觸發。適合
  • 📊 記錄操作結果（工具 + 輸入 + 時間戳 → JSONL 日誌）
  • 🔔 發送通知（Write 完成後 → Telegram 通知）
  • 🧹 格式化（Edit 完成後 → 自動 lint/format）
  • 💡 成本提示（Bash 執行後計算 token 消耗）
# observe-pattern.sh — 記錄所有工具操作 #!/bin/bash DATA=$(cat) mkdir -p $HOME/.claude/logs TS=$(date -u +%Y-%m-%dT%H:%M:%SZ) TOOL=$(echo "$DATA" | jq -r '.tool_name') INPUT=$(echo "$DATA" | jq -c '.tool_input') echo "{\"ts\":\"$TS\",\"tool\":\"$TOOL\",\"input\":$INPUT}" >> $HOME/.claude/logs/patterns.jsonl
Stop：Claude 準備結束 session 時觸發（最後一輪 response 送出後）。適合
  • 💾 自動存檔（session 結束 → 更新 MEMORY.md）
  • 🔍 完整性檢查（確認 TODO 都完成了）
  • 📬 結束通知（Telegram / Email 告知工作完成）
# save-session-state.sh #!/bin/bash SUMMARY=$(cat) # 接收 Claude 的最終 response TIMESTAMP=$(date +%Y%m%d-%H%M) echo "$SUMMARY" >> $HOME/.claude/logs/session-$TIMESTAMP.md echo "Session saved: $TIMESTAMP"
Exit Code 控制流
Hook 的 exit code 決定 Claude 接下來的行為。
0
放行（Continue）
Hook 執行成功，Claude 繼續原本的操作。stdout 的內容會回饋給 Claude 看。
1
阻擋（Block）
Claude 收到 Error，停止執行這個工具呼叫。stderr 的內容就是 Error 訊息。
2
警告（Non-blocking Error）
Hook 執行失敗，但不阻擋 Claude 繼續。Claude 可選擇忽略或採取行動。
# PreToolUse 阻擋危險操作範例 #!/bin/bash CMD=$(echo "$DATA" | jq -r '.tool_input.command // ""') if echo "$CMD" | grep -qE 'rm -rf|DROP TABLE|git push --force'; then echo "🚫 危險操作被攔截：$CMD" >&2 exit 1 # 阻擋 fi exit 0 # 放行
Matcher 模式測試器
輸入 matcher 正規表達式和工具名稱，即時測試是否命中。
✓ 命中
常用 matcher 參考：.*（全部）、Bash（只有 Bash）、Write|Edit（寫檔操作）、Read|Grep|Glob（唯讀操作）
